# Устройство проекта

Один модуль `app`, пакет `com.zubki.app`.

| Файл | Что делает |
|---|---|
| `MainActivity.kt` | вход, дата, запрос разрешения на уведомления, ставит напоминания при запуске |
| `data/Store.kt` | `Slot` (утро/вечер) и `Store`: отметки как состояние Compose для экранов |
| `data/Marks.kt` | запись и чтение отметок в SharedPreferences (`2026-10-12_m` → `08:14`), работает и из уведомлений с виджетом; `slotForNow(включённые времена)` выбирает утро или вечер по часам, с учётом выключенных |
| `data/ReminderSettings.kt` | включены ли напоминания, какие времена включены (утро, вечер, хотя бы одно), время утра и вечера |
| `data/Streak.kt` | подсчёт серии с паузой |
| `reminders/Reminders.kt` | будильники, уведомления, кнопки, «через 15 минут» |
| `reminders/Receivers.kt` | приёмники: будильник, кнопки уведомления, загрузка телефона |
| `reminders/Texts.kt` | тексты уведомлений, выбираются случайно |
| `widget/ZubkiWidget.kt` | виджет 1×1 |
| `ui/App.kt` | три вкладки внизу, таймер поверх них |
| `ui/TodayScreen.kt` | экран «Сегодня» |
| `ui/StreakScreen.kt` | серия, календарь месяца, значки |
| `ui/SettingsScreen.kt` | включение напоминаний, время утра и вечера |
| `ui/TimerScreen.kt` | таймер на 2 минуты |
| `ui/DayRing.kt` | кольцо дня и общий `Ring` |
| `ui/SlotCard.kt` | карточка «Утро/Вечер», галочка, `pressable` (нажатие с пружинкой) |
| `ui/SlotIcons.kt` | солнце и луна, нарисованы на Canvas |
| `ui/Parts.kt` | `SoftCard` и `PillButton` |
| `ui/Theme.kt` | палитра светлой и тёмной темы, цвета берутся через `palette` |

## Как это работает

- **Отметки.** Любое место, где можно отметиться (экран, кнопка в уведомлении, виджет), пишет через `Marks`. `Store` слушает SharedPreferences, поэтому экран обновляется сам. Виджет `Marks` обновляет после каждой записи.
- **Серия.** День засчитан, если отмечена хотя бы одна чистка. Один пропущенный день серию не рвёт (пауза), два подряд обнуляют. Сегодняшний день пропуском не считается. Значки считаются по лучшей серии.
- **Напоминания.** `AlarmManager.setAndAllowWhileIdle`: не нужны особые разрешения, зато время приблизительное. После срабатывания `AlarmReceiver` ставит следующее напоминание. После перезагрузки и обновления приложения их ставит `BootReceiver`. Если чистка уже отмечена, уведомление не показывается.
- **Виджет.** Нажатие отмечает чистку по времени суток: до 15:00 утро, позже вечер. Если уже отмечено, показывается подсказка. Если одно из времён выключено, нажатие отмечает оставшееся.
- **Утро и вечер.** В настройках каждое время включается отдельно, хотя бы одно остаётся (для тех, кто чистит раз в день). Выключенное время пропадает с экрана «Сегодня», из кольца, виджета, таймера и напоминаний. Старые отметки в нём сохраняются и видны в календаре.
- **Тесты.** `StreakTest` проверяет подсчёт серии. Запускаются в GitHub Actions, пока не блокируют сборку.

## Сборка

Gradle-обёртки в репозитории нет: Gradle ставится прямо в GitHub Actions. APK подписан ключом `app/zubki.keystore`, он лежит в репозитории осознанно (приложение личное, ключ нужен только для обновлений поверх). Номер сборки берётся из `GITHUB_RUN_NUMBER`.

Workflow сам проверяет, что файлы лежат в корне репозитория, а если сборка или тесты упали, выводит причину в Summary и Annotations страницы запуска (шаг «Показать причину ошибки»). Runner зафиксирован на `ubuntu-24.04`.

## Название

Видимое название «Чистка» (`app_name`, README, `chistka.apk`, заголовок релиза). Внутренние имена (`com.zubki.app`, `ZubkiWidget`, ключ `zubki.keystore`) остались прежними: от них зависят обновление поверх старой версии и сохранность отметок.

## Состояние

Все четыре этапа написаны: экран «Сегодня», уведомления и настройки, серия с календарём и значками, виджет и таймер. Первая сборка на GitHub упала: у `ReminderSettings` свойство `remindersOn` и функция `setRemindersOn` давали один JVM-метод (Platform declaration clash). Функцию переименовали в `enableReminders`. Правило на будущее: не называть функции `getX`/`setX`/`isX`, если в классе есть свойство `x`. Сборка после исправления ещё не проверена. Локально собрать проект нельзя, репозитории Google недоступны. Скриншотов в README пока нет.
